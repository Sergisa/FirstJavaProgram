# FirstJavaProgram

Здесь разберёмся как собирать проект с помощью Gradle
https://docs.gradle.org/current/samples/sample_building_java_applications.html

## Минимальный набор, чтобы заработало:

- gradlew.bat **(СКАЧИВАЕМ)**
- src/main/java/<package hierarchy> **(СОЗДАЁМ РУЧКАМИ: это наш код)**
- gradle/wrapper/ **(СКАЧИВАЕМ)**
    - ./gradle-wrapper.jar
    - ./gradle-wrapper.properties
- build.gradle **(СОЗДАЕМ РУЧКАМИ: настраиваем что и как надо собрать)**
- settings.gradle **(СОЗДАЕМ РУЧКАМИ: настраиваем что и как надо собрать)**
- compile.bat **(СОЗДАЕМ РУЧКАМИ: для удобства)**
